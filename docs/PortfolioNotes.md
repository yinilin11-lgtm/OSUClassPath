# Portfolio Notes

## Project Positioning

OSU CoursePath is positioned as an AI-powered academic course information assistant for Ohio State University students. The project demonstrates a complete software workflow: backend development, frontend interface design, database management, and AI API integration.

## Why the Name Was Updated

The repository name remains `OSUClassPath` to preserve the existing GitHub project history and URL. The public-facing project title was updated to **OSU CoursePath** because it is easier for professors, reviewers, and recruiters to understand at first glance.

## Portfolio Summary

OSU CoursePath shows experience with:

- Full-stack C# web development
- ASP.NET Core MVC architecture
- Entity Framework Core and SQLite
- AI-assisted user interaction through Gemini API
- Academic data organization
- GitHub project presentation

## Suggested Resume Description

Built OSU CoursePath, an AI-powered academic course information assistant using ASP.NET Core MVC, SQLite, Entity Framework Core, JavaScript, and Gemini API to help students explore course records, manage profiles, track selected classes, and ask course planning questions.
