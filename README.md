# OSUClassPath

OSUClassPath is an ASP.NET Core MVC web application for helping students explore course information and plan class paths.

## Features

- Course management
- Student management
- Student-course tracking
- SQLite database integration with Entity Framework Core
- AI chat interface for course planning support
- OpenAI API integration

## Tech Stack

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- JavaScript
- HTML/CSS
- OpenAI API

## Project Structure

- `Controllers/` - Handles web requests and application logic
- `Models/` - Defines course, student, and student-course data models
- `Views/` - Razor views for the web interface
- `Data/` - Entity Framework database context
- `Migrations/` - Database migration files
- `wwwroot/` - Static assets such as CSS and JavaScript
